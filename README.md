# **iOS SDK Рутокен**

Руководство по интеграции Рутокенов в ваш продукт на устройствах под управлением **iOS** и **iPadOS**.

### **Руководство в формате пошаговых уроков**

Материалы организованы в виде последовательных уроков, выполнение которых позволяет освоить технологический стек Рутокен и внедрить его в ваше приложение.

Уроки охватывают как базовые, так и продвинутые сценарии использования.

Ознакомиться с руководством можно [по ссылке](https://aktivco.github.io/sdk-ios/tutorials/tutorial-table-of-contents).

### **Примеры использования SDK**

Руководство сопровождается [примерами](https://github.com/AktivCo/sdk-samples-ios), иллюстрирующими типичные пользовательские сценарии. Они помогут быстрее разобраться и сократят время на внедрение.
